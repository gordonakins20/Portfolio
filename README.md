# Gordon Akins Portfolio

This repository contains a personal portfolio website built with HTML, CSS, and JavaScript.

## Overview

The site includes:
- A hero section and professional introduction
- Skills and project highlights
- Experience timeline
- Contact section
- Scroll reveal animations and dynamic year update

## Files

- `index.html` — main portfolio page
- `script.js` — updates the footer year and adds reveal-on-scroll behavior
- `styles.css` — site styling and layout

## Run locally

1. Open `index.html` in your browser, or
2. Serve the folder with a local web server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## GitHub Pages

To publish this site with GitHub Pages:

1. Push this repository to GitHub
2. In the repository settings, open Pages
3. Select the main branch and root folder (`/`)
4. Save the settings

Your site will be available at a URL like:

```text
https://gordonakins20.github.io/Portfolio/
```

## Customization

Edit the content in `index.html` to update:
- your name
- your professional summary
- skills
- projects
- experience
- contact information

If you want to make the design more personal, update the variables in `styles.css` and adjust the colors, spacing, and layout.
